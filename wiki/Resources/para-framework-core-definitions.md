# PARA Framework Core Definitions

## PARA Framework Core Definitions

The PARA method organizes information into four distinct categories:

- **Projects**: Short-term efforts with a specific goal and deadline.
- **Areas**: Ongoing responsibilities and standards to maintain over time.
- **Resources**: Topics of ongoing interest or reference materials.
- **Archives**: Completed or inactive items preserved for historical context.
